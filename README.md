# EOS Workbench

EOS Workbench wird eine kleine Webanwendung zur strukturierten Bearbeitung
eines Editorial-Operating-System-Content-Repositories.

- `eos-workbench` enthält Anwendung, technische Dokumentation, Tests und Releases.
- `eos-content` bleibt die private, dauerhafte Quelle für redaktionelle Inhalte
  und ihr Fachmodell.

Die Workbench unterstützt Observations, Topics und Publications sowie deren
Beziehungen, Metadaten und Inhalte.
Sie führt keine konkurrierende fachliche Datenhaltung ein.
Redaktionelle Freigabe und tatsächliche Veröffentlichung bleiben getrennt;
eine automatische Veröffentlichung ist nicht vorgesehen.

Das Repository beginnt mit der Einrichtung des Entwicklungsprozesses.
Programmiersprache, Framework, Architektur, Authentifizierung und Deployment
werden anschließend in eigenen technischen Konzeptionsaufträgen entschieden.
